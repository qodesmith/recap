# PROTOTYPE — Transcript & playback UI (#14)

Throwaway. Three radically different takes on the screen the user lives in,
switchable from the floating bar at the bottom (or `←` / `→`, or `?variant=A|B|C`).

```bash
bun install
bun run dev          # http://localhost:5173/?variant=A
```

Keys: `space` play/pause · `,` / `.` nudge ±5 s · `←` `→` switch variant.
Bottom bar also toggles **real ↔ stress** data and **reset**s all edits.

## The data is real

`src/data/transcript.json` is generated by `scripts/build-fixture.ts` from the
**actual #10 spike output** — Parakeet TDT v3 word timings + VBx diarization of a
34.5 min two-person call. 97 segments, 6,151 words, median segment 11.7 s,
**longest segment 3 minutes / 700 words**. That long tail is the whole reason to
prototype rather than sketch.

Two things are re-shaped, because the spike only had one mic:

- **Two tracks.** S1 → `Mic` (an attributed Track), S2 → `System audio (Zoom)`.
- **Real overlap.** Ten back-channels ("Yes.", "okay, can you") are moved into the
  middle of the Track-1 turn they interrupt — 11 overlapping pairs.
- **A deliberate diarization fault.** Short system-audio turns are split onto a
  bogus `Speaker 3`, so speaker-merge and segment-reassignment have real damage
  to repair.

`stress` mode repeats the recording 12× → 6.9 h, 1,164 segments, ~74k words.

## What each variant answers

| | **A — Conversation** | **B — Script** | **C — Studio** |
|---|---|---|---|
| Layout | chat bubbles, avatars, speaker rail | one column, screenplay gutter | track lanes + dense table |
| Sync | word highlight | segment tint + word underline | row highlight + word in active row |
| Follow | auto, silently off on scroll, "Jump to playhead" pill | auto-centre, off on scroll, toolbar re-arm | explicit toggle |
| Seek | click a word · waveform | gutter timestamp · waveform (**click = caret, not seek**) | scrub lanes · click block · timestamp · word |
| Edit | double-click → textarea, ⌘↵/blur commits, esc cancels | always editable, blur commits | explicit Save / Cancel |
| Edited marker | "edited" chip + revert | diff-style change bar in gutter | ✎ inline + revert |
| Rename | right rail, inline | the gutter name IS the field | left panel, inline |
| Reassign | drag bubble → rail, or chip menu | gutter ▾ menu, one at a time | **bulk**: select rows, press 1/2/3 |
| Overlap | "⇄ spoken over X" on the interrupter | interrupter indented under a rule | two blocks in one column + ⧉ badge |
| Export | header menu, hover-checkbox selection | native text selection → floating Copy/Export | action bar exports selected rows |
| Virtualized | yes | **no** (native selection + ⌘Z need the whole doc) | yes |

## Measurements (stress mode, 1,164 segments / 74k words)

| | first render | playback frames p50 / p95 / max |
|---|---|---|
| A | 37 ms (9 nodes mounted) | 17 / 38 / 84 ms |
| B | **1,727 ms** (1,164 paragraphs, 73,668 spans) | 17 / 18 / 22 ms |
| C | 84 ms (+1,164 lane blocks) | 17 / 73 / 205 ms |

Steady-state highlighting is cheap everywhere — the playhead never touches React
(see `highlight.ts`, the #5 "cursor is not React state" inference). The costs are
elsewhere: B pays at mount, C pays at every segment boundary (virtualizer
`scrollToIndex` + re-measure while following).

At V1's real worst case (2 h ≈ 340 segments) all three are fine.

## Deliberately not built

Real audio (the clock is fake — `transport.ts`), persistence, keyboard a11y,
undo, and any Tauri/IPC wiring. Export menus are stubs.
